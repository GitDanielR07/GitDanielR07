## Current Project

### SunTrace — AI-Assisted Solar Feasibility & Rooftop Planning System
*Capstone Project · Backend Developer · Ongoing, 2026*

A web-based decision-support system that automates rooftop solar feasibility assessment for solar providers and homeowners across Northern Luzon, built with an 8-member team in partnership with Glit Solar.

- Trained AI models for roof detection, roof sectioning, roof type analysis, and photovoltaic prediction, and connected them to the system
- Built the backend for report generation, surfacing environmental feasibility results, predicted monthly irradiance, recommended system specs, estimated cost/savings, and location conditions
